## AweGapps Awe

AweGapps Awe is a package of Google applications such as Play Store, Google
Play services and so on, made as light and minimal as possible; with the help
of Magisk it becomes systemless.

The apps bundled by this variant are listed in
`_litegapps_module_whitelist()` in `lib/litegapps.sh` (case `awe`). Override
that list for one build with `LG_PKGS_AWE="App1 App2 ..."`.
